# Master Prompts

A personal collection of reusable "master prompts" — carefully written prompt templates that I use repeatedly with AI assistants for recurring tasks.

## Why this repo?

Instead of rewriting the same detailed instructions every time, this repo stores them as version-controlled, reusable templates. Each prompt lives in its own file and can be copied directly into any AI chat tool (ChatGPT, Claude, etc.).

## Structure

Each master prompt is stored as a separate Markdown file in the [`prompts/`](./prompts) directory, named to describe its purpose.

## Prompts

- [`interview-keyword-cheatsheet.md`](./prompts/interview-keyword-cheatsheet.md) — Turns a prepared interview-answer document into a short keyword-chain cheat sheet (for oral recall practice) and a matching A4 poster text, output in German.

## Usage

1. Open the desired prompt file.
2. Copy its full content.
3. Paste it into your AI assistant of choice, along with any required input (e.g. your own document).
